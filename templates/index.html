Cara Setup WhatsApp Business API (Gratis)
1. Buka developers.facebook.com → My Apps → Create App → Business
2. Tambah produk WhatsApp ke app Anda
3. Di WhatsApp → Getting Started: catat Phone Number ID dan Access Token sementara
4. Untuk production: buat System User di Business Manager → generate permanent token
5. Daftarkan nomor WA bisnis → verifikasi → aktifkan
6. Paste Phone Number ID dan Token di bawah → Test → Simpan
⚡ Akun developer gratis: 1.000 pesan/bulan. Untuk unlimited pakai akun Business terverifikasi.
